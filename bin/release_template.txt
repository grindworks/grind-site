Release title
v1.8.0 - Offline-Ready Libraries & Security Hardening

Release notes
This release bundles every library GrindSite needs, so a site can be installed and run on a network with no internet access. It also fixes several security and reliability issues found in an audit, adds third-party license notices, and stops shipping the Bootstrap theme.

> [!IMPORTANT]
> **An update is performed by the version that is currently installed.** When you update to v1.8.0, your current version's updater is used, so the safer rollback described under "Updater" takes effect from your next update after this one.
>
> **Theme files are updated only when themes are allowed to update:**
> - **From v1.7.4:** Leave **"Do not update themes and skins"** unchecked (the default). Theme files that change are saved to `data/theme_backups/<date_time>/` first.
> - **From v1.7.3 or earlier:** The option is labeled **"Do not update/add themes and skins"** and is **checked** by default. While it is checked, the theme changes below are not applied. If you uncheck it, all bundled themes and skins are overwritten without saving copies, and deleted ones are restored, so copy any bundled theme you edited first.
>
> If you keep themes from updating, you can apply the theme change manually by replacing these files with the ones in `grindsite-v1.8.0.zip` (skip any theme you deleted, and re-apply your own edits). This is not a security fix:
> - `theme/default/layout.php`
> - `theme/corporate/layout.php`
> - `theme/marketing/layout.php`
> - `theme/neo-minimalist/layout.php`
> - `theme/nexus-docs/layout.php`
> - `theme/photographer/layout.php`

### 🔌 Offline / Intranet Use
- **KaTeX and Prism.js are bundled:** Math blocks and code highlighting (all Prism languages) now work without internet access. Prism is updated from 1.29.0 to 1.30.0, which fixes a known vulnerability (CVE-2024-53382).
- **Themes load the bundled Alpine.js first:** Previously, themes used the bundled copy only when "Disable External Assets (Local Fallback)" was checked. A CDN is now used only if the bundled file is missing.
- **Static export includes bundled libraries:** Static export skipped every folder named `vendor`, so exported sites were missing `assets/js/vendor/` and `assets/css/vendor/`. They are now exported.
- **CDN fallbacks are pinned:** When a bundled file is missing, the admin panel and themes load a fixed library version with Subresource Integrity, instead of "latest".
- For a fully offline site, check **"Offline Mode (Local Fallback)"** in the installer, or **Settings → Theme → "Disable External Assets (Local Fallback)"**. QR Code, Map and Embed blocks, link cards, update checks and license verification still need the internet.

### 🔒 Security & Reliability
- **Password-protected blocks fail closed:** If the server cannot encrypt the protected content (OpenSSL or AES-256-GCM unavailable), the content is now hidden instead of being shown unencrypted.
- **SVG sanitizer:** Dangerous namespaced attributes such as `xlink:href="javascript:..."` are now removed, and `@import` inside `<style>` is blocked. SVG upload remains admin-only.
- **Login page:** The "Back to site" link now rejects `redirect_to` values containing a backslash, like the post-login redirect already did.
- **License check:** A failed license check is now cached for one hour, so the admin panel no longer retries (and waits up to 5 seconds) on every page. After you save the General settings, a failed result is cleared and the key is checked again on the next page load.
- **Trusted proxy ranges:** Invalid prefix lengths (for example `/33`) are now rejected instead of causing errors.
- **Email 2FA plugin:** One-time codes are compared in constant time.

### ⬆️ Updater (applies to updates performed by v1.8.0 or later)
- **Honest rollback:** If an update fails, the rollback now checks every restored file and reports a failure instead of claiming success. Files that the failed update added are removed, so the site does not end up with a mix of old and new files.
- **Backup failures stop the update:** If a file cannot be backed up, the update stops before anything is changed.

### 🎨 Themes
- **Bootstrap theme removed:** The Bootstrap theme is no longer bundled. Updates never delete files, so if your site has `theme/bootstrap/`, it stays and keeps working as before, but it will not receive fixes and still loads Bootstrap from a CDN. We recommend switching to another theme.

### 📄 Licenses
- **`THIRD_PARTY_LICENSES.txt`:** New file listing every bundled third-party component (Alpine.js, Chart.js, flatpickr, KaTeX, Prism, Heroicons, Tailwind CSS and others) with its full license text.
- **Brand icons:** The social icons (X, Facebook, Instagram, LINE, Discord, TikTok, Pinterest, LinkedIn, GitHub, Threads, Twitch) now all come from Simple Icons (CC0), so their origin is documented. They keep the same names, so existing share buttons and themes keep working. The LINE icon is now single-color like the others.
- **`LICENSE.txt`:** Added Section 8, "Third-Party Components": bundled open source components are licensed under their own licenses, and this Agreement does not restrict those rights. The updater never changes `LICENSE.txt`, so download `grindsite-v1.8.0.zip` to read the new version.

### 📖 Documentation
- **README:** Updated the offline/intranet section, linked the third-party notices, and corrected the database file name (`data/grinds_*.db`).
- **Settings → Theme:** The description of "Disable External Assets (Local Fallback)" now matches the new behavior (all languages).

> [!IMPORTANT]

> - `theme/corporate/layout.php`

### 🔌 オフライン・イントラネットでの利用
- **KaTeX と Prism.js を同梱:** 数式ブロックとコードハイライト（Prism の全言語）が、インターネット接続なしで動作するようになりました。Prism は 1.29.0 から 1.30.0 に更新し、既知の脆弱性（CVE-2024-53382）を解消しました。
- **テーマは同梱の Alpine.js を優先:** これまでテーマは「外部アセットを無効化（ローカルフォールバック）」がオンのときだけ同梱版を使っていました。今後は同梱ファイルが無い場合にのみ CDN を使います。
- **静的書き出しに同梱ライブラリを含める:** 静的書き出しが `vendor` という名前のフォルダをすべて除外していたため、書き出したサイトに `assets/js/vendor/` と `assets/css/vendor/` が含まれていませんでした。今後は書き出されます。
- **CDN フォールバックのバージョン固定:** 同梱ファイルが無い場合、管理画面とテーマは「最新版」ではなく、バージョンを固定し SRI（サブリソース完全性）を付けたライブラリを読み込みます。
- 完全にオフラインで運用する場合は、インストール時に **「オフラインモード（ローカル優先）」** をチェックするか、**「システム設定 → テーマ → 外部アセットを無効化（ローカルフォールバック）」** を有効にしてください。QRコード・地図・埋め込みブロック、リンクカード、更新の確認、ライセンス認証はインターネット接続が必要です。

### 🔒 セキュリティ・信頼性
- **パスワード保護ブロックを fail-closed に:** サーバーが保護対象の内容を暗号化できない場合（OpenSSL または AES-256-GCM が使えない場合）、暗号化せずに表示するのではなく、表示しないようにしました。
- **SVG サニタイザ:** `xlink:href="javascript:..."` などの名前空間付きの危険な属性を除去し、`<style>` 内の `@import` をブロックするようにしました。SVG のアップロードは引き続き管理者のみです。
- **ログイン画面:** 「サイトに戻る」リンクで、バックスラッシュを含む `redirect_to` を拒否するようにしました（ログイン後のリダイレクトと同じ検査）。
- **ライセンス確認:** 確認に失敗した結果を1時間キャッシュするようにしました。管理画面を開くたびに再試行して最大5秒待たされることがなくなります。一般設定を保存すると失敗した結果が消去され、次にページを開いたときに再確認します。
- **信頼するプロキシの範囲指定:** `/33` などの不正なプレフィックス長を、エラーにならずに拒否するようにしました。
- **メール 2FA プラグイン:** ワンタイムコードを定数時間で比較するようにしました。

### ⬆️ 更新機能（v1.8.0 以降が行う更新に適用）
- **正確なロールバック:** 更新に失敗した場合、ロールバックで復元したファイルをすべて確認し、失敗があれば成功と表示せずに失敗として報告します。失敗した更新が追加したファイルは削除されるため、新旧のファイルが混在した状態になりません。
- **バックアップの失敗で更新を中止:** ファイルをバックアップできない場合は、何も変更する前に更新を中止します。

### 🎨 テーマ
- **Bootstrap テーマの同梱を終了:** Bootstrap テーマは同梱されなくなりました。更新でファイルが削除されることはないため、サイトに `theme/bootstrap/` がある場合はそのまま残り、従来どおり動作します。ただし今後は修正が届かず、Bootstrap も引き続き CDN から読み込みます。別のテーマへの切り替えをおすすめします。

### 📄 ライセンス
- **`THIRD_PARTY_LICENSES.txt`:** 同梱している第三者コンポーネント（Alpine.js、Chart.js、flatpickr、KaTeX、Prism、Heroicons、Tailwind CSS など）の一覧と、各ライセンスの全文を収録したファイルを追加しました。
- **ブランドアイコン:** SNS アイコン（X、Facebook、Instagram、LINE、Discord、TikTok、Pinterest、LinkedIn、GitHub、Threads、Twitch）をすべて Simple Icons（CC0）のデータに統一し、出典を明確にしました。アイコン名は変わらないため、既存の共有ボタンやテーマはそのまま動作します。LINE アイコンは他と同じ単色になりました。
- **`LICENSE.txt`:** 第8条「第三者コンポーネント」を追加しました。同梱のオープンソースコンポーネントにはそれぞれのライセンスが適用され、本契約はその権利を制限しません。更新機能は `LICENSE.txt` を変更しないため、新しい内容は `grindsite-v1.8.0.zip` をダウンロードしてご確認ください。
