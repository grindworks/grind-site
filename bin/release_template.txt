Release title
v1.7.3 - Security Fixes

Release notes
This patch release fixes several security issues found in an internal audit. Updating is strongly recommended for all sites, especially those with Editor accounts.

### 🛡️ Security Fixes
- **Block Output (XSS):** Fixed cases where Editor accounts could inject scripts through Callout, Countdown, Button, Card, Download, Audio, PDF, Testimonial and Internal Link blocks. Affected the core renderer and the Bootstrap, Classic, Corporate, Marketing and Photographer themes.
- **Uploads:** `.xml` files can no longer be uploaded. New installs now send `nosniff` and a script-blocking Content-Security-Policy for SVG/XML/HTML files in `assets/uploads/`.
- **Role Changes:** Demoting or deleting a user now takes effect immediately on their active sessions.
- **2FA & Strict Session Plugins:** Fixed a load-order bug that let both plugins silently fail open. They now work as described.
- **Feed Caches:** Sitemap, RSS and llms.txt caches are now separated per host, so a forged Host header can no longer poison them.
- **Session Cleanup:** Expired session files are now cleaned up during normal site traffic, not only when an admin opens the dashboard.
- **Updater:** Updates now abort unless the official package checksum is present and matches.

### 🔧 Bug Fixes
- **Public API:** `api/posts.php` no longer returns an error on every request. Out-of-range pages return the last page instead of redirecting to HTML.
- **Public API:** `api/settings.php` now returns the site description.
- **Countdown Block:** Finish messages are displayed as plain text consistently across all themes, and the default message is translated in the Marketing and Photographer themes.

### ⚠️ Action for Existing Sites (Apache)
The uploads protection above is written only on new installs. To apply it to an existing site, add the following to the top of `assets/uploads/.htaccess`:

```
<IfModule mod_headers.c>
    Header always set X-Content-Type-Options "nosniff"
    <FilesMatch "\.(?i:svg|xml|htm|html)$">
        Header set Content-Security-Policy "script-src 'none'"
    </FilesMatch>
</IfModule>
```

For nginx, add `xml` to the uploads CSP rule as shown in the README.

## 🇯🇵 日本語 (Japanese)

このパッチリリースは、内部監査で見つかった複数のセキュリティ上の問題を修正します。すべてのサイト、特に編集者（Editor）アカウントを使っているサイトでの更新を強く推奨します。

### 🛡️ セキュリティ修正
- **ブロック出力（XSS）:** 編集者アカウントが、コールアウト・カウントダウン・ボタン・カード・ダウンロード・音声・PDF・お客様の声・内部リンクの各ブロックからスクリプトを埋め込めた問題を修正。コアの描画処理と、Bootstrap・Classic・Corporate・Marketing・Photographer テーマが対象です。
- **アップロード:** `.xml` ファイルをアップロードできないようにしました。新規インストールでは、`assets/uploads/` 内の SVG/XML/HTML に `nosniff` とスクリプトを禁止する CSP を付けます。
- **権限変更:** ユーザーの降格や削除が、ログイン中のセッションにも即座に反映されるようになりました。
- **2FA・厳格セッションプラグイン:** 読み込み順の不具合により、両プラグインが有効化しても機能していなかった問題を修正しました。
- **フィードのキャッシュ:** サイトマップ・RSS・llms.txt のキャッシュをホストごとに分け、偽装した Host ヘッダで汚染できないようにしました。
- **セッションの掃除:** 期限切れのセッションファイルを、管理画面を開いたときだけでなく通常のアクセスでも削除するようにしました。
- **アップデート:** 公式パッケージのチェックサムが無い、または一致しない場合は更新を中止するようにしました。

### 🔧 不具合修正
- **公開API:** `api/posts.php` が常にエラーを返していた問題を修正。範囲外のページを指定した場合は、HTMLへリダイレクトせず最終ページを返します。
- **公開API:** `api/settings.php` がサイトの説明文を返すようになりました。
- **カウントダウンブロック:** 終了メッセージを全テーマで同じくテキストとして表示するよう統一し、Marketing・Photographer テーマで既定メッセージが翻訳されるようにしました。

### ⚠️ 既存サイトでの対応（Apache）
上記のアップロード保護は新規インストール時にのみ書き込まれます。既存サイトに適用するには、`assets/uploads/.htaccess` の先頭に次を追記してください。

```
<IfModule mod_headers.c>
    Header always set X-Content-Type-Options "nosniff"
    <FilesMatch "\.(?i:svg|xml|htm|html)$">
        Header set Content-Security-Policy "script-src 'none'"
    </FilesMatch>
</IfModule>
```

nginx の場合は、README のとおり uploads の CSP ルールに `xml` を追加してください。
