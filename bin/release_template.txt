Release title
v1.7.1 - Security Hardening & S-Rank UX Improvements

Release notes
This patch release focuses on enterprise-level security hardening and polishing the user experience to ensure GrindSite remains smooth, robust, and completely secure.

### 🛡️ Security & Defense in Depth
- **SSRF Protection:** Enforced IPv4 resolution to prevent DNS rebinding bypasses via IPv6.
- **Polyglot & LFI Prevention:** Added 2MB content scanning for all uploaded files (including images) to detect and block hidden PHP payloads.
- **XSS Prevention:** Enhanced escaping for Alpine.js attributes using JSON encoding.

### ✨ UX / UI Polishing (S-Rank)
- **BFCache Recovery:** Fixed an issue where native form buttons would remain disabled after navigating back in iOS Safari.
- **Editor UX:** Fixed the auto-resize bug for textareas, ensuring a smooth writing experience.
- **Media Modal:** Prevented arrow keys from accidentally switching images while typing in input fields.
- **Layout Fix:** Adjusted Z-index to prevent header dropdowns from clipping behind the editor toolbar.

## 🇯🇵 日本語 (Japanese)

このパッチリリースは、エンタープライズレベルのセキュリティ強化と、操作性を「Sランク」に引き上げるためのUX改善（ポリッシュ）に焦点を当てています。

### 🛡️ セキュリティと多層防御
- **SSRF対策の強化:** IPv6のDNSリバインディングを利用したバイパスを防ぐため、IP解決をIPv4に強制する防御を追加しました。
- **Polyglot/LFI対策:** 画像を含むすべてのアップロードファイルに対して、先頭2MBの走査を行い、隠されたPHPコード（ペイロード）を遮断するフェイルセーフを追加しました。
- **XSS対策:** Alpine.jsの属性展開において、JSONエンコードを活用したより強固なエスケープ処理を実装しました。

### ✨ UX / UI の改善
- **BFCache（戻るボタン）対策:** iOS Safari等で「戻る」操作をした際、送信ボタンが「Processing...」のまま凍結してしまう問題を完全に解消しました。
- **エディタの操作性向上:** テキストエリアの自動リサイズ機能が初期描画時に動作しないバグを修正しました。
- **メディア管理の競合解消:** 画像の詳細画面で文字入力中に矢印キーを押すと、意図せず別の画像に切り替わってしまう不快な挙動を防止しました。
- **レイアウト修正:** ヘッダーのドロップダウンメニューがエディタのツールバーの裏に隠れてしまうZ-indexの重なりバグを修正しました。
